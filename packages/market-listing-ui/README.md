# 市场列表增强

为开放插件市场的 DSH「发现」列表提供彩色指标标签。安装并启用后，star、下载量和带 `◷` 的更新天数显示在描述下方，作者保留。列表里的版本和日历日期隐藏，点击详情仍显示完整版本信息。

无需额外请求网络。插件仅处理含本索引指标前缀的列表条目，保留原生节点、点击与安装操作。停用即恢复原始列表。支持普通索引接入；未安装本插件时，DSH 继续以文字显示指标。

适配 DSH 0.2.1-rc.2 的列表结构。DSH 尚无单行市场卡片插槽，此插件通过客户端生命周期观察列表 DOM。遇到不匹配的结构时保留原生显示。未来客户端改版可能需要更新。

验证包含官方 EntryCard 生成的 DOM、筛选重绘、语言切换、重复渲染与停用恢复；也在真实 DSH 0.2.1-rc.2 的隔离本机实例中验证了列表、详情和安装确认。本机 desktop 配置已安装，显示效果由桌面截图确认。第三方插件的最终安装未执行。
